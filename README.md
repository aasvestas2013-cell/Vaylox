# Vaylox

An Unreal Engine 5 Battle Royale (Fortnite-inspired) game for solo developers.

## Features
- Battle Royale gameplay
- High-quality (realistic or stylized) graphics
- Multiplayer ready
- Modular C++/Blueprint codebase for solo-producibility

## Getting Started
1. Clone the repo
2. Open the project in Unreal Engine 5.x
3. Build and run!
